## 🚀 Deploy in 60 seconds

### Option A: Netlify (Drag & Drop)
1. Go to [app.netlify.com](https://app.netlify.com)
2. Sign in / create free account
3. Drag the entire `Blog/` folder onto the Netlify dashboard
4. Your site is live at `yoursite.netlify.app`

### Option B: GitHub Pages
1. Push this folder to a GitHub repository
2. Go to: **Settings → Pages → Source → GitHub Actions**
3. The workflow runs automatically on every push to `main`
4. Live at: `https://yourusername.github.io/Blog`
