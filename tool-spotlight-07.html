VirusTotal: Using It Well, and Its Limits

A colleague forwards an attachment: "Is this safe?" You upload it to VirusTotal and see "0 / 72". Clean. Or is it? A different file shows "3 / 72". Malware, or false alarm? VirusTotal is a superb tool, but the number at the top of the page is the least interesting thing it tells you, and uploading the wrong file can leak something you never meant to share.

Tool card What it is: an online service that checks files, URLs, domains and IP addresses against many security vendors
Cost: free for non-commercial web use; paid tiers for businesses, automation and hunting
Runs in: any web browser at virustotal.com, plus an API
Good for: a fast second opinion on suspicious files and links, and researching indicators
Watch out for: uploaded files may be shared with other VirusTotal customers
Skill level: beginner to use, experience needed to interpret

What VirusTotal Does

VirusTotal's documentation explains that it inspects items with over 70 antivirus scanners and URL and domain blocklisting services. Upload a file or submit a link, and within seconds you see what each of those engines thinks of it, along with a wealth of extra information: file details, behaviour from sandbox analysis, related domains and IP addresses, and comments from the security community.

It is important to understand what VirusTotal is not. Its documentation on false positives states that VirusTotal aggregates data from independent security vendors, does not produce its own verdicts, and cannot modify or remove detections made by those vendors. It is a meeting place for other people's opinions.

Never upload confidential files VirusTotal states that results are shared with the submitter and between the examining partners, and that the contents of submitted files or pages may also be shared with premium VirusTotal customers. Anything you upload, such as a contract, an invoice, an HR spreadsheet or an internal document, can end up readable by people outside your organisation. Search by hash first, and only upload files you would be comfortable making public.

How to Use It Well

  1. Search before you upload. Calculate the file's SHA-256 hash (for example with Get-FileHash in PowerShell, shasum -a 256 on a Mac, or CyberChef from Episode 06) and paste it into the search box. If the file has been seen before, you get the full report without sharing anything.
  2. Check links without clicking them. Paste a suspicious URL into the URL tab. VirusTotal fetches it from its own systems, not from your computer.
  3. Look up domains and IP addresses found in emails, logs or packet captures, such as those from Wireshark. The report shows reputation, related files and history.
  4. Read beyond the score. The Details, Relations, Behavior and Community tabs often tell you far more than the detection count.
The detection count is a starting point for thinking, not the end of it.

How to Read the Results

A clean result does not mean safe. Brand-new malware, targeted attacks and files built to evade antivirus may not yet be detected by any engine. "0 detections" means "no engine recognises this yet", nothing more. Treat a file from an unexpected source with suspicion regardless.

A few detections do not always mean malicious. With so many engines, some false positives are inevitable, especially for little-known software, installers, admin tools and anything packed or compressed. Look at which vendors flag it and what they call it. A generic, heuristic-sounding name from one or two engines is very different from a specific malware family name from many well-known vendors.

Context matters most. Ask:

  • When was the file first seen? A file first submitted an hour ago and attached to a surprise invoice is more worrying than one widely seen for years.
  • What does the Relations tab show? Contacting known malicious domains is a strong signal.
  • What did sandbox behaviour reveal? Dropping files in startup folders, launching PowerShell or contacting strange addresses are red flags.
  • What do community comments say? Analysts often add context, family names or links to reports.

If you are a software developer and your own legitimate program is flagged, VirusTotal's guidance is to click Reanalyse first and, if detections persist, report the false positive directly to the vendors that flagged it.

Where It Fits

  • Phishing triage. Check links and attachment hashes from reported emails, as part of Playbook Monday, Episode 01.
  • Incident response. Look up hashes of suspicious programs found by Sysmon or Process Explorer, and the domains they contacted.
  • Threat hunting. Paid tiers let analysts run YARA rules, from Episode 05, against VirusTotal's collection to find new samples.
  • Defanging and sharing. Share the VirusTotal report link rather than the file itself when discussing a sample.

Limits to Keep in Mind

  • It is not a replacement for antivirus. It scans one file when you ask; it does not protect your computer.
  • Attackers watch it too. Uploading a file from a targeted attack can alert the attacker that they have been spotted, because they can search for their own files' hashes.
  • Engine results on VirusTotal may differ from the full desktop products, which have extra layers such as behaviour monitoring and cloud lookups.
  • Free use has terms. The public web interface and API have usage limits and are not meant for commercial products or automated workflows without a paid licence.

Final Thoughts

VirusTotal gives anyone a second opinion from dozens of security vendors in seconds. Use it often, but use it wisely: search hashes before uploading, never upload anything confidential, and read the whole report rather than just the score. "Clean" and "malicious" are conclusions you reach, not numbers VirusTotal gives you.

Seventy opinions are better than one. They are still opinions, and the decision is yours.
